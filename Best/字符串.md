# Python 字符串处理全面指南

字符串是 Python 中最常用的数据类型之一，掌握字符串操作是 Python 编程的基础。以下是字符串的全面整理资料：

## 一、字符串基础

### 1. 创建字符串
```python
s1 = '单引号字符串'
s2 = "双引号字符串"
s3 = """多行
字符串"""
s4 = str(123)  # 将其他类型转为字符串
```

### 2. 字符串特性
- 不可变性：字符串创建后不能修改
- 有序性：字符按顺序排列，可通过索引访问
- 可迭代性：可用 for 循环遍历

## 二、字符串操作

### 1. 基本操作
```python
s = "Hello World"

# 长度
len(s)  # 11

# 索引
s[0]    # 'H' (第一个字符)
s[-1]   # 'd' (最后一个字符)

# 切片
s[1:5]  # 'ello' (索引1到4)
s[:5]   # 'Hello' (开始到索引4)
s[6:]   # 'World' (索引6到结束)
s[::2]  # 'HloWrd' (步长为2)
```

### 2. 字符串拼接
```python
s1 = "Hello"
s2 = "World"

# + 拼接
s1 + " " + s2  # "Hello World"

# join 方法
" ".join([s1, s2])  # "Hello World"

# f-string (Python 3.6+)
f"{s1} {s2}"  # "Hello World"
```

### 3. 字符串重复
```python
"Hi" * 3  # "HiHiHi"
```

## 三、字符串方法

### 1. 大小写转换
```python
s = "Python"

s.upper()      # "PYTHON"
s.lower()      # "python"
s.capitalize() # "Python"
s.title()      # "Python"
s.swapcase()   # "pYTHON"
```

### 2. 查找与替换
```python
s = "hello world"

# 查找
s.find("lo")       # 3 (返回索引，找不到返回-1)
s.index("lo")      # 3 (类似find，但找不到会报错)
s.count("l")       # 3 (统计出现次数)

# 替换
s.replace("l", "L") # "heLLo worLd"
s.replace("l", "L", 1) # "heLlo world" (只替换第一个)
```

### 3. 字符串判断
```python
s = "123abc"

s.isalpha()     # False (是否全字母)
s.isdigit()     # False (是否全数字)
s.isalnum()     # True (是否字母或数字)
s.islower()     # True (是否全小写)
s.isupper()     # False (是否全大写)
s.isspace()     # False (是否全空白字符)
s.startswith("123") # True
s.endswith("abc")   # True
```

### 4. 去除空白
```python
s = "  hello  "

s.strip()   # "hello" (去除两端空白)
s.lstrip()  # "hello  " (去除左端空白)
s.rstrip()  # "  hello" (去除右端空白)
```

### 5. 分割与连接
```python
s = "apple,banana,orange"

# 分割
s.split(",")       # ['apple', 'banana', 'orange']
s.split(",", 1)    # ['apple', 'banana,orange'] (最大分割次数)

# 连接
"-".join(["a", "b", "c"])  # "a-b-c"
```

## 四、字符串格式化

### 1. % 格式化
```python
name = "Alice"
age = 25
"Name: %s, Age: %d" % (name, age)  # "Name: Alice, Age: 25"
```

### 2. format() 方法
```python
"Name: {}, Age: {}".format(name, age)
"Name: {0}, Age: {1}".format(name, age)
"Name: {name}, Age: {age}".format(name="Alice", age=25)
```

### 3. f-string (Python 3.6+)
```python
f"Name: {name}, Age: {age}"
f"1+2 = {1+2}"  # "1+2 = 3"
```

## 五、字符串编码

### 1. 编码与解码
```python
s = "中文"
b = s.encode("utf-8")  # b'\xe4\xb8\xad\xe6\x96\x87'
b.decode("utf-8")      # "中文"
```

### 2. 常用编码
- UTF-8 (推荐)
- GBK (中文Windows常用)
- ASCII (仅支持英文)

## 六、转义字符

```python
\n  换行
\t  制表符
\\  反斜杠
\'  单引号
\"  双引号
\r  回车
\b  退格
```

## 七、原始字符串

```python
path = r"C:\new\folder"  # 不处理转义字符
print(path)  # C:\new\folder
```

## 八、字符串与列表转换

```python
# 字符串转列表
list("abc")  # ['a', 'b', 'c']

# 列表转字符串
"".join(['a', 'b', 'c'])  # "abc"
```

## 九、字符串性能优化

1. 大量字符串拼接使用 `join()` 而非 `+`
2. 频繁操作字符串考虑使用 `io.StringIO`
3. 格式化字符串优先使用 f-string

## 十、实用技巧

### 1. 反转字符串
```python
s = "hello"
s[::-1]  # "olleh"
```

### 2. 多行字符串
```python
s = """第一行
第二行
第三行"""
```

### 3. 字符串对齐
```python
s = "hello"
s.ljust(10)     # 'hello     '
s.center(10)    # '  hello   '
s.rjust(10)     # '     hello'
```

### 4. 检查子串
```python
"world" in "hello world"  # True
```

### 5. 去除特定字符
```python
"abc123".strip("abc")  # "123"
```
